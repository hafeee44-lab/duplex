Measurements

First time with this printer? Burn one scrap sheet — hit Test sheet below, print page 1, reinsert exactly as you plan to, print page 2. Hold it to the light: the two boxes should sit on top of each other and both arrows point the same way. Arrows opposing means tick “upside-down”; boxes not overlapping means switch the flip direction. Then it's solved for good.
In the print dialog set Scale 100% — never “Fit to page” — and margins to None. The PDF is locked to exact millimetres; page scaling is the one thing that can still ruin it.
